# customer-churn-prediction

## 📌 Project Overview
This machine learning project predicts whether a telecom customer will churn using the Telco Customer Churn dataset.  
It includes data preprocessing, encoding, Random Forest training, evaluation, and a real-time prediction demo.

## 🛠️ Technologies Used
- Python  
- Scikit-learn  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Jupyter Notebook  

## 📊 Model Performance
- **Model:** Random Forest Classifier  
- **Accuracy:** 80%  
- **Evaluation:** Confusion Matrix & Classification Report
